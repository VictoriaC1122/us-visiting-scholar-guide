# 把研究帶去另一座城市

Victoria 在準備期間持續整理的美國訪學札記。以第一人稱記下研究定位、尋找接待者、J-1 文件與生活安頓，也在文末留下一份給學弟妹的實用附錄。

線上閱讀：[我的美國訪學準備札記](https://victoriac1122.github.io/us-visiting-scholar-guide/)

## 特點

- 純 HTML、CSS、JavaScript，不需要建置工具。
- 版面延續個人網站的淡藍背景、白色紙張、襯線字與淡紫色點綴。
- 以可連續閱讀的長篇札記取代流程工具；桌機有章節旁註，手機有折疊目錄。
- 無 JavaScript 時仍可閱讀完整文章；列印時會自動展開文末附錄。
- 不含分析追蹤、私人聯絡方式、住址、精確行程或證件資料。
- 簽證與 J-1 內容附美國政府官方來源。

## 本機預覽

在專案根目錄啟動靜態伺服器：

```bash
python3 -m http.server 4173
```

然後開啟 `http://127.0.0.1:4173/`。

## GitHub Pages

本專案適合使用 GitHub Pages 的 `main` 分支、`/(root)` 發布。所有資源皆採相對路徑，可在 project page 子目錄正常載入。

## 資訊聲明

本站為個人經驗分享，不構成法律或移民建議。實際規定請以接待學校、J-1 Responsible Officer 與美國政府官方資訊為準。
