# 美國訪問學者申請與準備分享

Victoria 整理的美國訪問學者申請紀錄，包含研究規劃、聯絡接待教授、英文檢定、千里馬計畫、校方文件、J-1／AIT 面試、保險、住宿與實際費用。

線上閱讀：[美國訪問學者申請與準備分享](https://victoriac1122.github.io/us-visiting-scholar-guide/)

English: [My U.S. Visiting Scholar Application](https://victoriac1122.github.io/us-visiting-scholar-guide/en/)

## 文案風格

- 以 Victoria 的第一人稱與博士生身分撰寫，採成熟、克制的學術經驗散文語氣。
- 用具體經歷承接觀察，兼顧句子節奏與段落連貫；避免逐項報告的口吻、刻意口語、抽象感言與制式轉場。
- 文學性來自敘事、細節與措辭的分寸，不堆疊形容詞，不虛構情節、感受、資歷或研究成果。
- 研究經驗以連貫段落書寫，費用、文件與程序則保留便於查閱的表格及清單。
- 明確區分個人經驗與官方規定；金額、日期及文件名稱須可核對，未完成的事項應標示為待辦。
- 中英文維持相同的事實與進度，英文依自身語法與文體重寫，避免逐字翻譯。
- 英文能力段落客觀呈現校方標準、檢定結果與準備方式，不加入自我貶低或個人弱項評價。

## 特點

- 純 HTML、CSS、JavaScript，不需要建置工具。
- 使用 Noto Serif TC 閱讀字體與 Noto Sans TC 介面字體，搭配個人網站的柔和配色。
- 內容採編號章節、短段落與條列；桌機有章節目錄，手機有折疊目錄。
- 無 JavaScript 時仍可閱讀完整文章；列印時會自動展開文末附錄。
- 提供繁體中文與英文版本，並可從頁首切換語言。
- 不含分析追蹤、私人聯絡方式、住址、精確行程或證件資料。
- 個人紀錄只以去識別化摘要呈現，不公開私人信件、對話原文或文件截圖。
- 簽證與 J-1 內容附美國政府官方來源。

## 本機預覽

在專案根目錄啟動靜態伺服器：

```bash
python3 -m http.server 4173
```

然後開啟 `http://127.0.0.1:4173/`。

## GitHub Pages

本專案適合使用 GitHub Pages 的 `main` 分支、`/(root)` 發布。所有資源皆採相對路徑，可在 project page 子目錄正常載入。

## 資訊聲明

本站為個人經驗分享，不構成法律或移民建議。實際規定請以接待學校、J-1 Responsible Officer 與美國政府官方資訊為準。
