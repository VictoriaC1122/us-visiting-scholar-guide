# 美國訪問學者申請筆記

一個面向學弟妹與第一次準備美國訪問研究者的公開指南。內容涵蓋研究定位、接待單位、DS-2019、SEVIS、J-1 簽證、行前準備與抵達報到。

## 特點

- 純 HTML、CSS、JavaScript，不需要建置工具。
- 版面延續個人網站的淡藍背景、白色紙張卡片、Georgia 字體與紫色點綴。
- 桌機頁籤、手機下拉選單與完整鍵盤操作。
- 文件清單只保存於使用者本機瀏覽器，不會傳送資料。
- 不含分析追蹤、私人聯絡方式、住址、精確行程或證件資料。
- 簽證與 J-1 內容附美國政府官方來源。

## 本機預覽

在專案根目錄啟動靜態伺服器：

```bash
python3 -m http.server 4173
```

然後開啟 `http://127.0.0.1:4173/`。

## GitHub Pages

本專案適合使用 GitHub Pages 的 `main` 分支、`/(root)` 發布。所有資源皆採相對路徑，可在 project page 子目錄正常載入。

## 資訊聲明

本站為個人經驗整理，不構成法律或移民建議。實際規定請以接待學校、J-1 Responsible Officer 與美國政府官方資訊為準。
